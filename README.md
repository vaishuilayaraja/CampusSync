# 🎓 CampusSync - College Staff Management Portal

Full-Stack web application to manage college staff, departments, and leave requests. Built with the MERN Stack vibe but with MySQL.

### 🚀 Live Demo
Coming soon...

### ✨ Features
- **Role-Based Dashboards**: Separate views for Admin, HOD, and Staff
- **Staff Management**: CRUD operations for staff profiles  
- **Leave Management**: Apply, track, and approve leave requests
- **Department Overview**: View staff count and details per department
- **Secure Auth**: JWT-based login system

### 🛠️ Tech Stack
- **Frontend**: React.js, Tailwind CSS, Axios, React Router
- **Backend**: Node.js, Express.js
- **Database**: MySQL
- **Authentication**: JWT, bcrypt

### 📦 Setup Locally
```bash
git clone https://github.com/vaishuilayaraja/CampusSync.git
cd CampusSync

# Backend
cd server
npm install
npm start

# Frontend  
cd ../client
npm install
npm start
