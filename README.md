# 🎓 CampusSync - College Management System

A full-stack web application to digitize and streamline administrative operations of educational institutions. Built with React.js, Node.js, Express.js, and MySQL.

## ✨ Features

- **Role Based Access**: Separate dashboards for Admin and Staff
- **Student Management**: Complete CRUD operations with search and filter
- **Leave Management**: Apply, track and approve leave requests
- **Department Management**: Manage departments and courses efficiently
- **Secure Authentication**: JWT based login system
- **Responsive Design**: Works on all devices with Tailwind CSS

## 🛠️ Tech Stack

**Frontend:** React.js, Tailwind CSS, Axios  
**Backend:** Node.js, Express.js  
**Database:** MySQL  
**Authentication:** JSON Web Tokens (JWT)

## 🚀 Getting Started

### Prerequisites
- Node.js v18+ installed
- MySQL installed and running
